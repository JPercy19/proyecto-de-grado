# Control documental y de versiones

## Convención de nombres

`AAAA-MM-DD_tipo_descripcion_vX.Y.ext`

Ejemplo: `2026-08-27_matriz_requisitos_v0.1.xlsx`.

## Reglas

1. Conservar la fuente editable de cada figura, tabla, protocolo y resultado.
2. Registrar versión, fecha, responsable y cambio relevante.
3. Usar identificadores estables para requisitos, pruebas, riesgos y evidencias.
4. Vincular los documentos técnicos con el repositorio de código mediante enlace, etiqueta o hash de versión cuando aplique.
5. No modificar datos brutos; generar copias de análisis identificadas como tales.

## Revisión y aprobación

Los entregables que afecten seguridad, alcance, requisitos, selección de alternativa o interpretación de resultados deben revisarse con el director/a antes de declararse finales.
